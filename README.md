# WAVEROCK 디자인 툴

스태프용 디자인 툴 모음 페이지입니다.

- `index.html`: 모음 페이지. `tools.json`을 읽어 카드를 그립니다.
- `tools.json`: 툴 목록 (이름, 설명, 주소, 썸네일)
- `thumbs/`: 썸네일 이미지 (가로 16:10 권장)
- `ui.css`: 네 툴이 함께 불러오는 공통 색상과 "← 디자인 툴" 링크 스타일

## 새 툴 추가
모음 페이지 아래 **＋ 새 툴 추가**를 열고 안내대로 하면 됩니다.

## 공통 색 바꾸기
`ui.css`의 `:root` 값만 고치면 모든 툴에 함께 반영됩니다.
